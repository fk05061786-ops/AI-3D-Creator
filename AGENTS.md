# AI-3D-Creator Project Instructions

## Project Goal
Build and improve the existing AI-3D-Creator project.
Work only inside this existing project. Never create a duplicate project.

## Development Rules
- Inspect existing code before making changes.
- Preserve working features and existing architecture.
- Do not overwrite files without inspecting them.
- Make small, focused changes.
- Do not perform unrelated refactoring.
- Never delete existing backups.
- Do not expose API keys, tokens, passwords, or secrets.

## Strict Development Roadmap
- Current priority: Complete Phase 3 Advanced Modeling Tools.
- Do not begin Phase 4 AI Text-to-3D until Phase 3 is complete and approved.
- Ponytail skill must remain OFF. Never load or use it.

## Quality Requirements
- Check TypeScript errors before and after changes.
- Run ESLint on changed files.
- Run the production build when practical.
- Fix root causes instead of hiding errors.
- Report changed files, test results, and remaining issues.
- Ask before installing new dependencies or making destructive changes.
