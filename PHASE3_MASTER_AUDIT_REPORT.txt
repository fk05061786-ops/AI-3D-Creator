## CRITICAL - Split-Brain Wiring Bug

### Location
**File:** `src/ui/App.ts`, Line 27-24

### The Bug
```typescript
// Current (WRONG):
onToggleEditMode: () => {
  engine.toggleSculpting();  // ← Toggles SCULPTING, not EDIT MODE
  if (statusEl) statusEl.textContent = engine.isSculpting ? 'Sculpting Mode' : 'Modeling Mode';
}

// Should Be:
onToggleEditMode: () => {
  engine.toggleEditMode();  // ← Toggles EDIT MODE (onMeshEditor mode)
  if (statusEl) statusEl.textContent = engine.isEditMode ? 
    'Texture/Edit Mode' : 'Modeling Mode';
}
```

### Why This is Critical
- The Edit Mode button toggles **Sculpt Mode** instead of **Mesh Edit Mode**
- Sculpting requires selected mesh + sculpt brush
- Mesh edit mode (vertex/edge/face) requires `EditModePanel` which is CSS-invisible
- User cannot access vertex/edge/face selection, or any modeling operations

### Proof
```bash
$ grep -n "toggleSculpting\|toggleEditMode" src/ui/App.ts
27:  onToggleEditMode: () => { engine.toggleSculpting(); ...
```
The button calls `toggleSculpting()` (for brush sculpting) not `toggleEditMode()` (for mesh editing).

## Risk Assessment

### 🔴 CRITICAL (Breaks Phase 3)
1. **Edit Mode toggle calls Sculpt Mode**: Users cannot access vertex/edge/face selection without fixing.
2. **EditModePanel CSS missing**: UI is invisible, operations cannot be reached.

### 🟠 HIGH (Usability issues)
1. **ESLint 23 errors**: Code is technically working but violates style rules.
2. **Node.js deprecation warning**: `require('three')` in `main.ts` (unused file anyway).

### 🟡 MEDIUM (Incomplete features)
1. **`main.ts` not integrated**: Contains deprecated single-object demo code.
2. **Undefined class in EditorEngine**: `ModifierSystem` used but class not imported.
3. **`position` attr out of bounds in inset**: Not verified but could cause glitches.

### 🟢 LOW (Nice to have)
1. **No polygon growth limits in subdivision**: May create excessive geometry on repeated subdivisions.
2. **Inefficient edge detection for complex meshes**: O(n²) on high-poly models.
3. **No mobile gesture refinements**: Basic pinch/zoom work but could be smoother.
