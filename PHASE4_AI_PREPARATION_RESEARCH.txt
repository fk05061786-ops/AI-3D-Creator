## 1. SUITABLE FREE AND OPEN-SOURCE TEXT-TO-3D MODELS

### Candidate A: Shap-E (OpenAI)
- **Type:** Text-to-3D / Image-to-3D conditional implicit neural representations.
- **License:** MIT License.
- **Maintenance Status:** Released by OpenAI (2023); stable, community-maintained.
- **Compatibility:** Python / PyTorch; exports to mesh/GLB via marching cubes.
- **Resource Requirements:** ~4GB–8GB VRAM (runs on mid-range GPUs, or CPU slowly).
- **Verified Facts:** MIT-licensed, open weights available on Hugging Face (`openai/shap-e`).
- **Limitations:** Low-poly outputs; lacks fine semantic details (good for basic props and primitives).

### Candidate B: Point-E (OpenAI)
- **Type:** Text-to-3D point cloud diffusion model followed by mesh extraction.
- **License:** MIT License.
- **Maintenance Status:** Stable open-source release.
- **Compatibility:** Python / PyTorch.
- **Resource Requirements:** ~2GB–4GB VRAM (very lightweight).
- **Verified Facts:** Extremely fast generation (~10-20 seconds on GPU).
- **Limitations:** Generates point clouds that require post-processing (marching cubes) to form solid meshes; surface quality can be grainy.

### Candidate C: InstantMesh / TripoSR (Stability AI & Tripo3D)
- **Type:** Feed-forward Image-to-3D reconstruction.
- **License:** MIT License (TripoSR) / Apache 2.0 (InstantMesh).
- **Maintenance Status:** Highly active community support (2024–2026).
- **Compatibility:** Python / PyTorch / ONNX / WebAssembly (via server wrapper).
- **Resource Requirements:** ~6GB–8GB VRAM (TripoSR), ~12GB VRAM (InstantMesh for high-res).
- **Verified Facts:** Generates high-quality textured 3D meshes from a single image in <0.5 seconds on a modern GPU.
- **Limitations:** Requires an image input (Image-to-3D); for Text-to-3D, requires a 2D text-to-image generator (e.g., SDXL-Turbo / Stable Diffusion) as a first stage.

## 2. RELEVANT GITHUB REPOSITORIES

1. **TripoSR (`cvlab-st/TripoSR`)**
   - *Description:* Fast feed-forward 3D reconstruction from a single image.
   - *License:* MIT.
   - *Compatibility:* Python 3.10+, PyTorch 2.0+.
2. **Shap-E (`openai/shap-e`)**
   - *Description:* Generate 3D assets from text prompts or images.
   - *License:* MIT.
   - *Compatibility:* PyTorch, Transformers.
3. **InstantMesh (`TencentARC/InstantMesh`)**
   - *Description:* Efficient 3D mesh generation from single images using multiview diffusion.
   - *License:* Apache 2.0.
   - *Compatibility:* PyTorch, Diffusers.

## 4. LOCAL VS. CLOUD GPU EXECUTION

- **Local Execution:** Viable on desktop developer machines with NVIDIA GPUs (RTX 3060/4060 or better). Not feasible directly on mid-range Android mobile devices due to VRAM limitations.
- **Cloud GPU Execution:** Required for mobile (Android) users. The Capacitor app will send prompts/images to a lightweight backend API (Python FastAPI) hosted on a cloud GPU.

### Free / Low-Cost Cloud GPU Options
1. **Google Colab (Free Tier):** T4 GPU available intermittently. Good for testing, but session timeouts prevent production API hosting.
2. **Hugging Face Spaces (Free Tiers):** CPU basic is free; GPU (T4 small) available at low cost or free community quotas. Excellent for hosting a TripoSR/Shap-E microservice endpoint.
3. **RunPod / Vast.ai:** Pay-as-you-go (~$0.20–$0.50/hr for RTX 3090/4090). Requires credit card / payment details (no free lunch without credit card).

## 5. ANDROID APP INTEGRATION ARCHITECTURE

1. **Client (Capacitor / Android App):** User enters prompt in AI panel.
2. **API Request:** App sends HTTP POST request (`/api/generate-3d`) with prompt to Python backend.
3. **Backend Processing:** Backend runs Shap-E / TripoSR, generates GLB file, and uploads to temporary storage or streams back.
4. **Import:** App receives GLB binary, passes to `GLBImporter`, and adds resulting `SceneObject` into `EditorEngine` and `SceneGraph`.
